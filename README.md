# Data Quest

A Python data project that combines commands, analytics, coordinates, progress tracking, inventory, streams, and data transformation.

## Exercises

- Command and score processing
- Coordinate-system calculations
- Achievement tracking
- Inventory management
- Data streams
- Data alchemy and transformation

Each exercise builds a small reusable component and practises clear data modelling.

This activity has been created as part of the 42 curriculum by amigdadi.
